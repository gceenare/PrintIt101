# PrintIt101
A web-based 3D t-shirt customization platform that allows users to upload designs, place them accurately on a 3D shirt model, and track position, rotation, and scale for production-ready output.

About

PrintIt101 is a 3D t-shirt customization platform where users upload logos/designs, position them on a 3D shirt model, and export production-ready coordinates for printing.

Features

- Upload and position design assets
- Track position, rotation, and scale for production
- Export print-ready data

Tech Stack

- Java (server) and web frontend

Quick start

```bash
# clone
git clone https://github.com/gceenare/PrintIt101.git
cd PrintIt101
# open README for client/server details
```
